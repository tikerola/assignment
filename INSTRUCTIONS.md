# UI Test Automation Assignment

## Assignment

Build an efficient UI automation suite using either **Playwright (TypeScript or Python)** or **Robot Framework**.

- **Target site:** https://www.saucedemo.com/
- Implement **4–6 automated tests** that best cover the site's core features and key risks.

## Engineering Requirements

- Tests must use a **web browser** (no API-only solutions).
- No fixed sleeps.
- Use a clear locator strategy and avoid brittle selectors.
- Use a maintainable test structure (Page Objects or a clear Keyword structure).
- Provide a **one-command test run**, documented in `README.md`.
- AI tools are allowed and recommended.

## Deliverables

- **Code**
- **`README.md`** — Document the exact commands required to set up and run the test suite in a clean environment.
- **`test_design.md`** _(max. 1 page)_ — Describe the key features and risks selected for testing, the reasoning behind the selection, and how the test suite validates them.
- **`ai_usage.md`** _(max. 10 lines)_ — Briefly describe how AI was used during the assignment.
